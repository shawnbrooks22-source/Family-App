🌟 Kindo — Your Setup Checklist

Open this in Chrome or Safari → File → Print → Save as PDF  |  Do these steps in order. Each one builds on the last.

1

Run npm install on your computer

5 min · Your laptop

Your app uses a shopping cart plugin called react-native-iap to handle subscriptions. Running npm install is like pressing "Download" so the plugin actually shows up on your computer.

  1. Open Terminal (Mac: press Cmd+Space, type Terminal, hit Enter).
  2. Type cd ~/Family-App and press Enter to go to your project folder.
  3. Type npm install and press Enter. Wait for it to finish (takes about 1–2 minutes).
  4. You'll see something like "added 312 packages" — that means it worked!
2

Run the database schema in Supabase

10 min · supabase.com

Your database is like a filing cabinet. Right now some drawers are missing labels. This step adds the missing labels (columns, security rules, and a photo storage bucket) so everything saves correctly.

  1. Go to https://supabase.com and log in.
  2. Click your Kindo project.
  3. In the left sidebar click SQL Editor.
  4. Click + New query.
  5. Open the file supabase/schema.sql from your project folder in any text editor, select ALL the text (Cmd+A), copy it (Cmd+C).
  6. Paste it into the Supabase SQL editor and click Run (green button, top right).
  7. You should see "Success. No rows returned." — that means it worked!
Tip: If you see a red error saying something already exists, that's usually fine — it just means part of it ran before. Scroll down to check the rest ran OK.
3

Deploy the two Edge Functions

10 min · Terminal + Supabase

Edge Functions are little helper programs that live on Supabase's servers. One deletes accounts safely, the other handles Stripe payment alerts. You need to upload them so they're live.

  1. In Terminal, make sure you're in your project folder: cd ~/Family-App
  2. If you haven't installed the Supabase CLI yet, run: npm install -g supabase
  3. Log in to Supabase CLI: npx supabase login — it will open your browser to confirm.
  4. Link your project (replace YOUR_PROJECT_REF with the ID from your Supabase project URL):
    npx supabase link --project-ref YOUR_PROJECT_REF
  5. Deploy the delete-account function:
    npx supabase functions deploy delete-account --no-verify-jwt
  6. Deploy the Stripe webhook function:
    npx supabase functions deploy stripe-webhook --no-verify-jwt
  7. Both should say "Deployed successfully".
Where's my project ref? Go to supabase.com → your project → Settings → General. It's the string after "Reference ID".
4

Add secret keys to your Edge Functions

5 min · supabase.com

Your Edge Functions need two secret passwords to work — one lets them delete accounts safely, and one lets them verify Stripe is really talking to them. You add these like hiding a key under a mat.

  1. Go to supabase.com → your project → Settings → Edge Functions.
  2. Click Add new secret.
  3. Add secret #1: Name = SUPABASE_SERVICE_ROLE_KEY, Value = your service role key (found in Settings → API → "service_role" key).
  4. Add secret #2: Name = STRIPE_WEBHOOK_SECRET, Value = you'll get this in Step 5 — come back and add it after.
5

Set up Stripe webhook

10 min · stripe.com

Stripe needs your app's address so it can tap you on the shoulder when a payment fails or a refund happens. A webhook is just Stripe's way of sending you a text message.

  1. Go to https://dashboard.stripe.com and log in.
  2. In the left sidebar click Developers → Webhooks.
  3. Click + Add endpoint.
  4. For the URL, paste your Supabase Edge Function URL — it looks like:
    https://YOUR_PROJECT_REF.supabase.co/functions/v1/stripe-webhook
  5. Under Select events, search for and check these two:
    payment_intent.payment_failed
    charge.refunded
  6. Click Add endpoint.
  7. On the next page click Reveal signing secret — copy that value.
  8. Go back to Step 4 and paste it as the STRIPE_WEBHOOK_SECRET.
6

Create the subscription product in App Store Connect

20 min · appstoreconnect.apple.com

You need to tell Apple "hey, I'm selling a $X/month subscription called Kindo Premium." Without this, the upgrade button in the app won't show a price and purchases won't work.

  1. Go to https://appstoreconnect.apple.com and log in.
  2. Click your Kindo app → Monetization → Subscriptions.
  3. Click + to create a Subscription Group — name it Kindo Premium.
  4. Inside that group, click + to add a subscription.
  5. Set the Product ID to exactly: kindo_premium_monthly (must match exactly!)
  6. Set the duration to 1 Month.
  7. Click Add Localizations → add a display name (Kindo Premium) and description.
  8. Click Set Price → choose your monthly price (e.g. $4.99).
  9. Save everything.
Tip: Apple requires a Privacy Policy URL before you can submit. That's your kindo.app/privacy link — set it up in Step 8 first if needed.
7

Create the subscription product in Google Play Console

20 min · play.google.com/console

Same as Step 6, but for Android. Google Play needs its own copy of the product listing.

  1. Go to https://play.google.com/console and log in.
  2. Click your Kindo app → Monetize → Subscriptions.
  3. Click Create subscription.
  4. Set Product ID to exactly: kindo_premium_monthly
  5. Add a name (Kindo Premium) and description.
  6. Under Base plan, click Add base plan → choose Auto-renewing → set your monthly price.
  7. Click Activate to make it live.
8

Host your Privacy Policy and Terms pages

15 min · Your website host

Apple and Google require every app to have a real Privacy Policy on the internet. You already wrote them — you just need to put them online at your kindo.app website.

  1. Find the two files in your project: legal/privacy.html and legal/terms.html.
  2. Upload privacy.html to your web host so it's reachable at https://kindo.app/privacy.
  3. Upload terms.html so it's reachable at https://kindo.app/terms.
  4. Open both URLs in your browser to confirm they load.
Don't have hosting yet? The easiest free option is Netlify Drop — go to https://app.netlify.com/drop, drag your legal folder in, and it gives you a live URL in seconds. You can then set a custom domain.
9

Create an EAS account and link your app

10 min · expo.dev

EAS is Expo's build service — it's the machine that packages your app into an actual .ipa (iPhone) or .apk (Android) file you can submit to the stores. Think of it like a printing press for your app.

  1. Go to https://expo.dev and create a free account.
  2. In Terminal, run: npm install -g eas-cli
  3. Log in: eas login
  4. In your project folder, run: eas build:configure
  5. It will ask questions — choose All for platform, and say Yes to creating a new project.
  6. This updates your app.json with the correct project ID automatically.
10

Create a Sentry account for crash reports

10 min · sentry.io

Sentry watches your live app 24/7 and texts you (via email) when something crashes. Like having a security camera for bugs — you'll see exactly what went wrong and on which phone.

  1. Go to https://sentry.io and create a free account.
  2. Create a new project → choose React Native.
  3. Sentry will show you a DSN — it looks like https://abc123@o123.ingest.sentry.io/456. Copy it.
  4. In your project folder, open the file .env (or create it by copying .env.example).
  5. Find the line EXPO_PUBLIC_SENTRY_DSN= and paste your DSN after the equals sign.
  6. Save the file.
11

Add your app icon and splash screen

15 min · Your computer

Right now the app has a placeholder star icon. You need a real icon to submit to the App Store — Apple requires a 1024×1024 pixel PNG image with no rounded corners (Apple rounds it for you).

  1. Create or export your app icon as a PNG file, 1024×1024 pixels, no transparency, no rounded corners.
  2. Name it icon.png and place it in your project's assets/ folder, replacing the existing one.
  3. For the splash screen, create a PNG, 1284×2778 pixels (iPhone 14 Pro Max size). Name it splash.png and place it in assets/ too.
  4. Open app.json and confirm these lines exist:
    "icon": "./assets/icon.png"
    "splash": { "image": "./assets/splash.png" }
  5. Need a quick icon? Try https://www.canva.com — search "app icon", design yours, export as PNG 1024×1024.
Do these in this order:
1 → 2 → 3 → 4 → 5 → 8 → 6 → 7 → 9 → 10 → 11

Once all 11 are done, come back and we'll run your first EAS build and submit to the stores!
