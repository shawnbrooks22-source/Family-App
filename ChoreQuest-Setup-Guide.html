Collaboration Setup Guide

Private & Confidential — For Your Eyes Only
🔒 A Note on Ownership
Your code is automatically protected by copyright the moment it's written — no registration needed. To protect your project: keep the GitHub repo private, don't share credentials, and document your development history (git commits act as timestamped proof). If this grows into a business, consult a lawyer about forming an LLC and filing a trademark.

1 Put ChoreQuest on a Private GitHub Repo

GitHub is where your code lives in the cloud. Both of you will access the project from there. This step is done once by you (Shawn).

Step 1a — Create a GitHub account (if you don't have one)

1
Go to github.com Click "Sign up" and create a free account. Remember your username.

Step 1b — Create a new private repository

1
Click the "+" icon (top right) → "New repository"
2
Fill in the details: Repository name: ChoreQuest  |  Set to Private  |  Do NOT check "Initialize this repository"
3
Click "Create repository" — GitHub will show you a page with setup commands. Keep it open.

Step 1c — Push your existing code to GitHub

Open Command Prompt in your Family-App folder and run:

git init
git add .
git commit -m "Initial ChoreQuest app"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/ChoreQuest.git
git push -u origin main
Replace YOUR_USERNAME with your actual GitHub username. GitHub will ask you to log in — use your GitHub email and password (or a personal access token if prompted).

2 Invite Your Girlfriend as a Collaborator

This lets her access the private repo with her own GitHub account.

1
She creates a free GitHub account at github.com — she needs to pick a username and remember it.
2
You go to your repo: github.com/YOUR_USERNAME/ChoreQuest → Settings → Collaborators → "Add people"
3
Type her GitHub username and click "Add collaborator". She'll get an email to accept the invite.
4
She accepts the invite from her email — she now has full access to the repo.
✅ At this point: Both of you can see and edit the code. She can never lock you out — you're the owner of the repo.

3 Set Up Her Computer

She needs to do these steps on her own laptop/PC. These are one-time installs.

Step 3a — Install Node.js

1
Go to nodejs.org → Download the LTS version (the button that says "Recommended For Most Users") → Install it.
2
Verify it worked — open Command Prompt and run: 
node --version
You should see something like v20.x.x

Step 3b — Install Expo CLI

npm install -g expo-cli

Step 3c — Install Git

1
Go to git-scm.com → Download and install Git for Windows (or Mac). Use all default options during install.

Step 3d — Install the Expo Go app on her phone

Search for "Expo Go" in the App Store (iPhone) or Google Play (Android) and install it.

4 She Clones the Project

This downloads the code to her computer.

1
Open Command Prompt and navigate to where she wants to store the project: 
cd Desktop
2
Clone the repo: 
git clone https://github.com/YOUR_USERNAME/ChoreQuest.git
cd ChoreQuest
3
Install dependencies: 
npm install --legacy-peer-deps
4
Start the app: 
npx expo start
Scan the QR code with Expo Go on her phone — the app should appear!

5 Set Up Claude Code on Her Computer

Claude Code is the AI coding assistant you've been using. She needs her own Anthropic account.

Step 5a — Create an Anthropic account

1
Go to claude.ai and sign up for a free account with her email.
2
For Claude Code (CLI), go to console.anthropic.com → Sign up / Log in → Go to "API Keys" → Create a new key → Copy it (you only see it once!).

Step 5b — Install Claude Code

npm install -g @anthropic-ai/claude-code

Step 5c — Log in

claude

It will ask for her API key — paste the one she copied. She's now logged in.

Step 5d — Open the project in Claude Code

cd Desktop/ChoreQuest
claude

She can now ask Claude Code to help her build features, fix bugs, and more — just like you have been!

6 How to Work Together Without Conflicts

Follow these rules so you don't accidentally overwrite each other's work.

Action Command Who / When
Get the latest code before starting work git pull origin main Both of you — always do this first
Save your work to GitHub git add .
git commit -m "what you did"
git push origin main		 Both of you — after every session
Check what changed git status Both of you — anytime
See recent changes git log --oneline Both of you — anytime
Golden Rule: Always git pull before you start working, and always git push when you're done. This keeps both of you in sync and prevents lost work.

7 Daily Workflow — Quick Reference Card

Every time you sit down to work:

# 1. Go to the project folder
cd Desktop/ChoreQuest        (or wherever it's saved)

# 2. Get the latest code
git pull origin main

# 3. Start the app
npx expo start

# 4. Open Claude Code in another terminal window
claude

# 5. When done, save your work
git add .
git commit -m "describe what you built today"
git push origin main
Tip for Claude Code: You can just describe what you want in plain English — "Add a points system for kids" or "Make the buttons bigger" — and Claude will write the code for you. You don't need to know how to code!
